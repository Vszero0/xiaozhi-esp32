本模块不包含代码，仅由 ESP-IDF 原生 CSV 格式的分区表文件组成，被 `partitions.csv` 入口通过 `include!` 或条件编译选择具体版本。
- `v1/`：传统布局，固定包含 `model`（spiffs，存放内置模型/主题），配合 `factory` app 分区；针对 4m/8m/16m 及带自定义唤醒词 / Echo Ear 的变体提供独立 CSV。
- `v2/`：新布局用 `assets`（spiffs）替代 `model`，将应用体积压缩并留出更大空间给可网络下载的唤醒词、主题、字体、音效等动态资源；同时支持双 OTA（`ota_0`/`ota_1`）与 32MB 大闪存设备；`README.md` 记录了各配置的尺寸分配与从 v1 迁移步骤。
依赖方向单向：上层固件通过 ESP-IDF 的 partition table API 读取这些 CSV 生成的地址常量，本模块不反向依赖任何源码。
