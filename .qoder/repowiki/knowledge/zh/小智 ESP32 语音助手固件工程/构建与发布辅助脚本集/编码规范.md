- 每个可执行脚本以 `#!/usr/bin/env python3` shebang 开头并通过 `argparse` 暴露 CLI 参数，同时提供 `if __name__ == "__main__": main()` 入口。
- 对外部工具（idf.py、pngquant、pack_model.py 等）一律通过 `subprocess.run(..., check=True)` 调用，失败时打印错误并 `sys.exit(1)`，避免静默失败。
- 路径操作统一基于 `os.path` 拼接，并在访问前用 `os.path.exists` 检查，不存在时打印 Warning 而非抛异常，保证脚本在缺省资源下仍可继续。
- 生成的中间产物（index.json、config.json、assets.bin）写入固定目录结构（如 `build/assets`、`build/output`），并以 JSON indent=4 + ensure_ascii=False 写出，便于人工核对。
- 子包内的可选依赖采用 try/except ImportError 包裹并在缺失时抛出明确提示（如 LVGLImage.py 对 pypng/lz4 的检查），配合同级 `requirements.txt` 管理。
