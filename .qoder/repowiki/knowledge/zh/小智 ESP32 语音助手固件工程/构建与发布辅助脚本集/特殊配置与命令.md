- 运行 `python scripts/release.py --list-boards [--json]` 列出所有 board 变体；`python scripts/release.py <board_type>` 编译并打包该板的所有 variant 到 `releases/`。
- `python scripts/versions.py` 遍历 `releases/*.zip`，解析 merged-binary.bin 后上传至 OSS 并 POST info.json 到 `VERSIONS_SERVER_URL`（需配置 `OSS_*` 环境变量）。
- `python scripts/spiffs_assets/build.py --wakenet_model ... --text_font ... --emoji_collection ...` 构建 SPIFFS assets；`python scripts/build_default_assets.py --sdkconfig ... --output ...` 为 IDF 构建流程提供零依赖替代方案。
- `pip install -r scripts/<subdir>/requirements.txt` 安装对应工具链后再运行。
