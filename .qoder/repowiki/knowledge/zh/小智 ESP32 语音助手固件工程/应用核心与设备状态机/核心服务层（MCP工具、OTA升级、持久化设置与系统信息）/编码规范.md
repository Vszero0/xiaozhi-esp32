- 每个源文件顶部定义统一的 `#define TAG "..."` 并通过 `ESP_LOGI/W/E` 输出日志，便于串口过滤。
- 对外部资源访问一律通过单例 `Board::GetInstance()` 获取（如 GetNetwork/GetDisplay/GetAudioCodec/GetCamera），避免直接 include 底层驱动。
- 长耗时或可能阻塞的操作（相机拍照、HTTP 下载、屏幕快照上传）通过 `Application::Schedule` 投递到主线程执行，并在回调中用 try/catch 捕获异常后返回错误响应。
- Settings 采用 RAII 模式：构造函数打开命名空间、析构函数 commit 并关闭句柄；读写操作前检查 `read_write_` 标志，非写模式仅告警而不抛错。
- HTTP 请求统一通过 `SetupHttp()` 注入通用 Header（Activation-Version、Device-Id、Client-Id、Serial-Number、User-Agent、Accept-Language、Content-Type），再由具体业务设置 Content 与 URL。
- 版本比较与参数校验走辅助函数（`ParseVersion`/`IsNewVersionAvailable`、`PropertyList` 类型匹配），不在业务分支里内联实现。
