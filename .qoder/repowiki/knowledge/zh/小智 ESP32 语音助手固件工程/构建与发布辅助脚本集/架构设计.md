本模块是纯脚本目录，按职责拆分为若干独立子包与顶层单文件脚本，彼此无运行时依赖：
- `spiffs_assets/`：SPIFFS assets 分区构建管线，`build.py` 作为入口，通过 `subprocess` 调用同目录的 `pack_model.py`（生成 srmodels.bin）和 `spiffs_assets_gen.py`（将 assets 目录打包为带 mmap 表头的 assets.bin），并生成 index.json/config.json；`build_all.py` 用于批量触发。
- `Image_Converter/`：LVGL 图片转换器，核心 `LVGLImage.py` 封装 ColorFormat/CompressMethod 枚举及 pngquant/lz4 外部工具链，`lvgl_tools_gui.py` 提供 GUI 前端，依赖由 `requirements.txt` 声明。
- `p3_tools/`：协议 v3 音频流工具集，`convert_audio_to_p3.py` 使用 librosa+opuslib+pyloudnorm 做重采样/响度归一化/Opus 编码，`play_p3.py`/`p3_gui_player.py` 负责播放，`batch_convert_gui.py` 提供批量转换界面。
- `acoustic_check/`：声学检测分析工具，`main.py` 驱动 demod/graphic 完成解调与图形输出。
- `ogg_converter/`：小智专用 OGG 转换器 `xiaozhi_ogg_converter.py`。
- 顶层脚本：`release.py` 扫描 `main/boards/*/config.json` 收集变体，解析 Kconfig 符号与 target 推导 CONFIG_BOARD_TYPE_xxx，调用 `idf.py set-target/build/merge-bin` 产出 releases/v{ver}_{name}.zip；`versions.py` 从 releases zip 中解析 app desc 提取芯片/板卡信息，经阿里云 OSS SDK 上传并 POST 到版本服务器；`build_default_assets.py` 是 spiffs_assets 管线的“零依赖”内联版，直接读取 sdkconfig 推断 wakenet/multinet/font/emoji 并生成 assets.bin；`gen_lang.py`、`download_github_runs.py`、`mp3_to_ogg.sh`、`sonic_wifi_config.html` 等为配套辅助工具。
依赖方向：各子包仅依赖标准库或各自 requirements.txt 中的第三方包，不互相 import；对外部工具的调用统一通过 `subprocess` 或系统 PATH 查找，保持脚本可移植性。
