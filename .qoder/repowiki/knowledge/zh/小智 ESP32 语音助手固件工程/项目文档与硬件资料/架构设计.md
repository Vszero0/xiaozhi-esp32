纯静态文档目录，按版本与主题组织：
- `v0/`、`v1/` 子目录存放对应固件版本的设备接线图与实物照片（jpg/png），作为 README 或 wiki 的配图资源。
- 根目录下以中英文成对命名（`xxx.md` / `xxx_zh.md`）提供多语言对照文档，包括 MCP 协议定义与使用示例（`mcp-protocol.md`、`mcp-usage.md`）、MQTT over UDP 与 WebSocket 传输协议、BLUFI 配网流程、自定义开发板接入指南（`custom-board.md`）以及基于 clang-format 的代码风格规范（`code_style.md`）。
- 文档本身不参与构建系统，仅作为仓库级参考材料被 README 或其他页面引用。
